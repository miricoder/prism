## 🔐 Security Architecture

### API Key Management
✅ **AES-256-GCM Encryption**
- All API keys (Claude, OpenAI) are encrypted at rest
- Keys are **never logged or exposed** to the frontend
- Encryption key stored as env var (not in code)
- Settings page provides masked input fields with show/hide toggle

### Database
✅ **MongoDB Atlas**
- Username: `miralihomes_db_user`
- Database: `ultimate-planner-dev`
- Passwords hashed using bcryptjs (10 rounds)
- User sessions stored in JWT tokens

### Authentication
✅ **NextAuth.js with Credentials**
- Passwords never stored in plain text
- Session tokens signed and verified
- Auto-creates users on first login (demo-friendly)

## 🌿 Branching + Vercel Deployment Workflow

PRISM uses a **branch-per-capability** workflow with Vercel **Preview Deployments** for testing and `main` as the only **Production** source.

### Branch rules

- **`main`**: production-only (must always build + lint)
- **`cap/<capability>`**: feature/capability branches (e.g. `cap/travel`, `cap/resume`)
- Optional: **`fix/<topic>`** for urgent hotfixes

### Vercel rules

- **Production Branch**: `main`
- Every push to any non-`main` branch produces a **Preview URL**

### Promote Preview → Production

- Push to `cap/*` → test the Preview URL (mobile + desktop)
- When accepted → open PR → merge into `main`

### Rollback

- **Fast rollback (Vercel)**: promote a previous Production deployment in Vercel
- **Source rollback (Git)**: revert the merge commit in `main` and redeploy

4. **Click the trash icon** to delete the 0.0.0.0/0 rule

5. **Click "+ Add IP Address"** to add specific IPs

6. **Add your dev machine:**
   - Whitelist: `203.45.67.89/32` (replace with your IP)

   - Click "Confirm"

7. **Add Vercel's ranges:**
   - Whitelist: `2001:2600:1700::/48`

## 📞 Troubleshooting

### "MongoDB connection failed"
- Check `.env.local` has correct DATABASE_URL
- Verify your IP is whitelisted in MongoDB Atlas (Network Access)
- Try from your machine: `curl ifconfig.me` to check your IP

### "ENCRYPTION_KEY must be 32 bytes"
- Ensure ENCRYPTION_KEY in `.env.local` is exactly 64 hex characters
- Run `openssl rand -hex 32` to generate a new key if needed

### "Port 3000 already in use"
```bash
lsof -i :3000  # Find process
kill -9 <PID>  # Kill it
npm run dev    # Try again
```

### "NextAuth secret not set"
- Ensure `NEXTAUTH_SECRET` is in `.env.local`
- Value can be any random string (generated in setup)
